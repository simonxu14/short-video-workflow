# 平台现场手册（实测）

发布全程靠浏览器现场操作，本页记录实测过的坑。页面改版后以现场为准，并把新发现补回本页。

## 通用

- **登录态预检是逐个平台观察**，发现当前站登录/验证码阻塞就立即按browser-use交接规则，不能为扫完五端而推迟；交接超时不代表用户拒绝/通过，恢复只观察原页。
- 页面交互由当前browser-use Skill决定，本手册只提供业务目标。优先新鲜ref→动作→观察；支持的upload_file优先，CDP仅用于确实不支持的深层文件input。不得盲用旧选择器、临时节点或页面像素。
- 窄视口导致offscreen/obscured时先滚动和重观察，确认可交互层及遮挡。截图像素/DPR不能直接当视口坐标；不盲目覆写视口，覆写不生效或布局与可见区域不一致时恢复原布局再取新观察。
- 标签输入后等待实际校验/候选形成，再逐个确认已关联；输入成功≠标签关联成功。开关必须读取选中状态，合成JS click/PointerEvent无报错≠成功，不强行绕过控件/授权。
- 上传前先核对目标input所属控件（视频上传区还是封面编辑器）、`accept`和文件类型；多input时用已观察的控件限定目标，不能笼统用第一个 `input[type=file]`。报“视频格式不支持jpg/png”先排查图片误入视频入口，不据此断言平台不支持图片。
- 封面先打开真实编辑按钮；替换后保存并回看实际缩略图，确认不是默认帧。提交前逐项核验：当前批准版本的账号、视频、封面、文案、真实关联话题、AI/原创、可见性、位置、定时开关；同一原表单占位后提交一次，之后只观察结果。
- `PREPARED`保存原表单，`SUBMITTING/SUBMITTED/UNKNOWN`不重新start/重传。用户明确停发的分支保持停发，不能因“全平台默认”补发。
- 发布后必须看到后台列表里的本作品并截图；`done` 只凭截图记账，「提交成功」弹窗不算证据。
- 后台显示「已发布」≠ 公开可验证，不夸大成公开验证。

## 后台时间的时区口径

| 平台 | 后台时间口径 | 实测依据 |
|---|---|---|
| B站 | 北京时间（+08） | 稿件管理时间 |
| 小红书 | 北京时间（+08） | 笔记管理时间 |
| 抖音 | 跟随运行设备时区（本机当时 -05/-04，不是北京时间） | 后台时间与本机投稿日志同分钟；曾误按 +08 记，后纠错 |
| 快手 | 跟随运行设备时区 | 待发布/作品管理时间 |
| 视频号 | 跟随运行设备时区（曾见 05:28 = UTC 的记录，也有本机时区的记录） | 页面不标时区，**拿不准就不要写 published_at**，只用后台列表时间建复查待办 |

记录时间时优先「后台显示 + 本机时区锚点」对照核定；无法独立核验就留空，不要猜。

## 抖音 creator.douyin.com

- 上传后自动跳 `post/video`，标题是独立字段（30 字内），话题在正文里 `#xxx` 空格确认。
- 自主声明选「内容由AI生成」（radio），下拉后有「确定」。
- 封面可以选竖/横帧；首帧若没有人物，手动换一帧。
- 发布后跳内容管理；新作品可能需稍后出现，只有当前原投稿后台列表“已发布”才记终态。点击后触发短信验证或超时，保留原页/占位并查原投稿，不重上传或再点发布。

## 快手 cp.kuaishou.com

- 作者声明是级联选择框：「为作品添加补充说明」→ 选「内容为AI生成」；键盘 ArrowUp/Enter 比鼠标稳。
- 话题硬上限 **4 个**。
- 封面编辑可以直接点帧条上的缩略帧 → 确认。
- **坑**：作品管理页默认时间范围会弹「时间范围不能大于1年」错误，列表显示「共0个作品」。绕路：首页「最新作品/发布作品」核对；或在管理页自己把时间范围收窄到一年内再搜。
- 发布后若列表没有明确「已发布」字样，保守记 UNDER_REVIEW，不猜。

## B站 member.bilibili.com

- 上传可能带入默认标签，先核对并移除不相关项。新标签**逐个输入→等待候选/校验→Enter确认→读取真实已关联标签**，不要连续批量Enter；本期曾只保留首个标签，必须核对数量和文字。
- 页首“发布视频”是页面标题，不是提交按钮；实际提交控件为“立即投稿”（曾观察到 `span.submit-add`）。先现场定位再滚动/重观察，窄范围DOM定位只按当前browser-use规则使用，不盲点标题、旧class或坐标。点击后只等/查原结果。
- 创作声明选“含AI生成内容”；分区按本期批准方案，不固定套“影视”（古典音乐内容可为“音乐→古典音乐”）。
- 封面打开真实“添加封面”编辑器后，从已上传视频的推荐帧选与批准画面相符的帧，回看4:3/16:9预览→“完成”→确认弹窗消失及表单缩略图保存。编辑器“智能”栏曾提供视频帧候选，不把选帧当重新生成图片；不需要点“智能生成封面”。若候选不符批准帧，改用准确定位的封面input；不静默换方案。可见范围核对“公开可见”，定时关。
- 删除上传项前核对该项文件名、所属卡片与确认框目标，封面误入视频列表时不能删掉正确视频。重传/新开表单不修复未知投稿；仍按resume先查原稿件。
- 上传/替换素材后可能回填文件名并清空声明。提交前回读实际标题、分区、关联标签、AI/原创和封面，与批准发布包逐项对照，不只验证刚才输入成功。
- 投稿后去稿件列表核对当前作品（不只看总数），已发现重复稿/配置不符用 `issue open` 留痕；作品已发布不代表整期收尾完成。
- 稿件管理里能拿到 BV 号（`a[href*=BV]`），直接记为 post_id。

## 小红书 creator.xiaohongshu.com

- 标题 **≤20 字**；正文里用「话题」按钮或 `#xxx` + Enter 关联，确认显示为蓝色话题胶囊。
- 原创声明开关 → 弹窗勾选「我已阅读并同意《原创声明须知》」→ 声明原创。
- 内容类型声明选「笔记含AI合成内容」。父容器点击可能不触发真实开关，下沉到当前可交互层并读取选中状态；面板没展开先排查遮挡，不默认PointerEvent能解决。
- 最终发布按当前browser-use小红书publish分支交接用户，账号/内容/可见性说清。超时保留同一编辑页，不冒充完成或重新上传；实际返回后重观察，才记录受理/终态。
- 发布成功页后去「笔记管理」核对（能看到已发布/审核中、浏览数），web 端没有公开笔记链接。
- 封面编辑里可以逐帧选，弹窗底部有「完成」。

## 视频号 channels.weixin.qq.com

- 登录经常失效：到 login.html 就交接扫码，别自己点。
- **上传input可能在 `wujie-app` 的shadowRoot里**，点上传区可能触发系统文件框。普通upload找不到时，在当前browser-use许可范围内用CDP：先 `DOM.enable`，再 `DOM.performSearch(query="input[type=file]", includeUserAgentShadowDOM=True)` → `DOM.getSearchResults`；逐个用 `DOM.describeNode` 核对节点类型/accept/所属上传控件，只对已确认的视频input调用 `DOM.setFileInputFiles(files=[实际母版绝对路径], nodeId=当前节点)`。不要给所有候选注入文件，不沿用旧nodeId；页面变化后重新定位。可用的Runtime objectId路径也必须先核对实际目标。
- 上传调用成功不等于完成：回看缩略图/文件名、进度或处理状态；处理完再核对标题、原创及AI声明，然后提交一次。
- 短标题是独立输入框；话题直接打进描述。现场短标题可能拒绝逗号等标点，提前校验；若需改动已批准文案，先在未投稿时按版本绑定规则更新并取得本次批准，不能暗改外发正文。
- 位置默认可能带「北京市」，改成「不显示位置」。
- 声明原创 → 原创权益弹窗勾同意须知 → 声明原创；视频标注选「含AI生成内容」。
- 发表后跳视频管理；原创声明通常先显示「**原创审核中**」，这是原创标记审核，不要据此推断内容是否公开。复查时列表显示「已声明原创」再改 PUBLISHED。
- 封面编辑里点帧条选帧（人物帧优先），再点确认。
