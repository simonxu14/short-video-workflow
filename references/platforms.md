# 平台现场手册（实测）

发布全程靠浏览器现场操作，本页记录实测过的坑。页面改版后以现场为准，并把新发现补回本页。

## 通用

- **发布前登录态预检**：五个平台的后台一次全部打开一遍；登录失效的先交接扫码，不要做到一半停。
- 上传一律用页面里的 `input[type=file]` 或 CDP 注入，**不要点「选择文件」触发系统文件框**（会卡住自动化）。
- 发布后必须看到后台列表里的本作品并截图；`done` 只凭截图记账，「提交成功」弹窗不算证据。
- 后台显示「已发布」≠ 公开可验证，不夸大成公开验证。

## 后台时间的时区口径

| 平台 | 后台时间口径 | 实测依据 |
|---|---|---|
| B站 | 北京时间（+08） | 稿件管理时间 |
| 小红书 | 北京时间（+08） | 笔记管理时间 |
| 抖音 | 跟随运行设备时区（本机当时 -05/-04，不是北京时间） | 后台时间与本机投稿日志同分钟；曾误按 +08 记，后纠错 |
| 快手 | 跟随运行设备时区 | 待发布/作品管理时间 |
| 视频号 | 跟随运行设备时区（曾见 05:28 = UTC 的记录，也有本机时区的记录） | 页面不标时区，**拿不准就不要写 published_at**，只用后台列表时间建复查待办 |

记录时间时优先「后台显示 + 本机时区锚点」对照核定；无法独立核验就留空，不要猜。

## 抖音 creator.douyin.com

- 上传后自动跳 `post/video`，标题是独立字段（30 字内），话题在正文里 `#xxx` 空格确认。
- 自主声明选「内容由AI生成」（radio），下拉后有「确定」。
- 封面可以选竖/横帧；首帧若没有人物，手动换一帧。
- 发布后跳内容管理；新作品可能需要等几十秒或刷新一次才出现，列表「已发布」才算数。

## 快手 cp.kuaishou.com

- 作者声明是级联选择框：「为作品添加补充说明」→ 选「内容为AI生成」；键盘 ArrowUp/Enter 比鼠标稳。
- 话题硬上限 **4 个**。
- 封面编辑可以直接点帧条上的缩略帧 → 确认。
- **坑**：作品管理页默认时间范围会弹「时间范围不能大于1年」错误，列表显示「共0个作品」。绕路：首页「最新作品/发布作品」核对；或在管理页自己把时间范围收窄到一年内再搜。
- 发布后若列表没有明确「已发布」字样，保守记 UNDER_REVIEW，不猜。

## B站 member.bilibili.com

- 上传后会自动带入默认标签（如「音乐游戏」「自制谱」），逐个关掉再打自己的标签。
- 创作声明选「含AI生成内容」；分区选「影视」。
- 封面从系统推荐帧里点选；可见范围默认「公开可见」，定时发布保持关。
- 稿件管理里能拿到 BV 号（`a[href*=BV]`），直接记为 post_id。

## 小红书 creator.xiaohongshu.com

- 标题 **≤20 字**；正文里用「话题」按钮或 `#xxx` + Enter 关联，确认显示为蓝色话题胶囊。
- 原创声明开关 → 弹窗勾选「我已阅读并同意《原创声明须知》」→ 声明原创。
- 内容类型声明选「笔记含AI合成内容」。
- 发布成功页后去「笔记管理」核对（能看到已发布/审核中、浏览数），web 端没有公开笔记链接。
- 封面编辑里可以逐帧选，弹窗底部有「完成」。

## 视频号 channels.weixin.qq.com

- 登录经常失效：到 login.html 就交接扫码，别自己点。
- **上传 input 在 `wujie-app` 的 shadowRoot 里**，且点上传区会触发系统文件框。正确做法（CDP）：
  ```python
  r = bu.cdp('Runtime.evaluate',
             expression="document.querySelector('wujie-app').shadowRoot.querySelector('input[type=file]')")
  bu.cdp('DOM.setFileInputFiles',
         files=['/绝对路径/master.mp4'], objectId=r['result']['objectId'])
  ```
- 短标题是独立输入框；话题直接打进描述。
- 位置默认可能带「北京市」，改成「不显示位置」。
- 声明原创 → 原创权益弹窗勾同意须知 → 声明原创；视频标注选「含AI生成内容」。
- 发表后跳视频管理；原创声明通常先显示「**原创审核中**」，这是原创标记审核，不要据此推断内容是否公开。复查时列表显示「已声明原创」再改 PUBLISHED。
- 封面编辑里点帧条选帧（人物帧优先），再点确认。
